# 629 Burdette St · Kitchen - 360° tour

Day / night interactive 360° tour + photo gallery (Maureen Stevens Design · visualisation MS3DSTUDIO).

## Parlor

Live: https://ms3dstudio.github.io/629-burdette-tour/parlor.html

| File | What it is |
|---|---|
| `parlor.html` | Parlor viewer page, same UI as the kitchen and bath pages, plus an Adjust panel (brightness, contrast, clarity, texture) |
| `parlor_tour.js` | Parlor tour data: one spot in the middle of the room and its five views |
| `pano_parlor01.jpg` | Parlor 360, 6000×3000 equirectangular (yaw 0 = north wall, 90 = foyer side, 180 = sofa and window wall) |
| `pano_parlor01_m.jpg` | 4096×2048 copy for phones and low-memory GPUs |
| `og_parlor.jpg` | Link preview image |

Adjust (top right) sets brightness, contrast, clarity and texture. A link can carry a setting, for example `parlor.html?br=20&ct=10&cl=40&tx=30`.
